# GUDEV Spring GameJam 2026

**Theme:** Time

A top-down arcade shooter with Superhot-style mechanics. Time only moves when you do.

## How to open
Godot 4.3 — open the folder and select `project.godot`.

## Controls
- **WASD** — Move
- **Mouse** — Aim
- **LMB** — Shoot (costs 10s)
- **Shift** — Dash (costs 3s, brief invincibility)

## Objective
Collect 5 cores to unlock the exit portal. Optional coins to 100% the level.

## Features
- Time is your health — getting hit costs seconds
- Kill enemies to earn time back (+5s per kill)
- Chain kills within 3s for a combo multiplier (up to x4)
- Rare Time Freeze pickups restore +15s
- Screen shake on damage
